# Outils RCP

Outils pédagogiques sur l'arrêt cardiaque pour les formations sapeurs-pompiers :

- **Défibrillation** : moniteur ECG simulé (rythme sinusal, asystolie, fibrillation ventriculaire), effet du choc, cœur faible après le choc, FV réfractaire.
- **Chances de survie** : chronomètre et graphe évolutif (10 % par minute sans geste, environ 3,5 % avec massage).
- **Compressions** : métronome 100 à 120/min, cycles 30/2 et 15/2, compressions seules, insufflations seules, relais toutes les 2 min, mesure du rythme avec le capteur du téléphone.
- **Chronologie en équipe** : pendant un exercice, on note chaque action ; débriefing avec fraction de compressions, pauses de plus de 10 s, délais (1re compression, DAE, choc, O₂, alerte) et relais.
- **Ce qui change en 2026** : nouveautés des fiches arrêt cardiaque, ILCOR / ERC / AHA.

Repères tirés du référentiel départemental SSUAP du SDIS 88 (version juillet 2026). Outils de démonstration : ils ne remplacent ni le référentiel ni les indications du DAE.

Appli web installable, fonctionne hors ligne. Aucune donnée collectée.
